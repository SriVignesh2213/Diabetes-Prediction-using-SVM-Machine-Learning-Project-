# 🩺 Diabetes Prediction using SVM (Machine Learning Project)

## 📌 Project Overview

This project focuses on predicting whether a person is diabetic or not using Machine Learning techniques. A Support Vector Machine (SVM) model is trained on medical data to classify patients based on health parameters.

---

## 🚀 Features

* Data preprocessing and cleaning
* Train-test split for model evaluation
* Machine Learning model using **Support Vector Machine (SVM)**
* Prediction system for new input data
* Simple and easy-to-understand workflow

---

## 🧠 Technologies Used

* Python 🐍
* NumPy
* Pandas
* Scikit-learn
* Matplotlib (for visualization)


## 📊 Dataset

The dataset contains medical attributes such as:

* Glucose
* Blood Pressure
* BMI
* Insulin
* Age
* DiabetesPedigreeFunction
* Pregnancies 

Used to predict diabetes outcome.

---

## 🎯 Result

The SVM model predicts whether a person is:

* **Diabetic**
* **Non-Diabetic**

with good accuracy after training and evaluation.
